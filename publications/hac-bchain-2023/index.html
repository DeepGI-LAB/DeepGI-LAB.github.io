HAC-Bchain: A Secure and Scalable Blockchain-Shard Based E-Voting System

Authors

Sohel Ahmed JoniRabiul RahatNishat TasninPartho GhoseL Gaur

Abstract

This paper proposes HAC-Bchain, a secure and scalable blockchain-shard based e-voting system using the Hierarchical Authoritative Consensus (HAC) model. The system balances transparency with voter privacy while maintaining high throughput.
