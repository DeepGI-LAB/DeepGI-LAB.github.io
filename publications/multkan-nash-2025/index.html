MultKAN-Nash: Strategic Multi-Agent Disaster Response using MultKAN and Nash Equilibriums

Authors

Sohel Ahmed JoniNishat TasninSorna DasAhmed ShafkatSamin YasarBijon Mallik

Abstract

This paper presents MultKAN-Nash, a strategic multi-agent disaster response system that leverages the MultKAN architecture and Nash Equilibrium game theory for optimal resource allocation during emergencies. The system analyzes flood data and processes it into agent utilities via MultKANs.
